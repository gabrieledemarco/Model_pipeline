Enhancement Descriptions

A · Volatility-scaled sizing (vol_target = 0.20)

Scales position size inversely to realised 20-bar hourly vol (rvol_20), targeting 20% annualised portfolio volatility. High-vol periods (2022 bear, 2024 ETF pump) get smaller positions automatically. Scalar is clipped [0.25, 3.0]. No signal changes — only affects how much risk is taken per trade.

B · Adaptive composite threshold (rolling 75th-pct, 90d window)

Instead of a fixed threshold of 3.0, the entry bar requires composite ≥ p75(|composite| over past 90 days). In high-activity regimes the bar rises automatically (fewer, stronger signals); in quiet regimes it stays near the base threshold of 3.0. Applied symmetrically for shorts.

C · Daily EMA-200 regime filter

Only longs when 1H close > daily EMA(200); only shorts when 1H close < daily EMA(200). Prevents trading against the medium-term trend (~6-month). Particularly effective for filtering the 2020-2021 bull run where the composite system was generating incorrect short signals.

D · Signal persistence filter (N=2 bars)

A signal fires only when the composite has been above the threshold for 2 consecutive 1H bars (not just the current one). Eliminates single-bar spikes and whipsaw entries in choppy consolidations. The trade-off is slightly later entries but higher signal quality.

A2 · Vol sizing + DD circuit breaker (vol_target=0.20, dd_halt=15%)

Combines volatility targeting with an equity circuit breaker: when drawdown from peak exceeds 15%, position size is halved; at 22.5% trading pauses entirely until equity recovers above 15% DD. Designed to capture the upside of vol targeting while hard-limiting tail drawdowns.
